# Research Operations Handbook

This repository holds the research operations handbook for the model-efficiency
program, together with the shared toolkit used across the project repositories.

- `docs/operations.md` - operating notes and the open action items catalog.
- `docs/project-index.md` - index of the program's project repositories.
- `toolkit/` - shared scheduling, storage, and metrics helpers.
- `pipelines/` - ingestion and evaluation pipelines.
- `scripts/` - command-line entry points.
- `configs/` - default configuration files.
- `tests/` - unit tests for the shared toolkit.

All project repositories live in the same account and follow the
`<program>-<slug>-<suffix>` naming convention.
